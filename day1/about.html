About QuickNotes

QuickNotes is a simple application for capturing ideas and important reminders quickly. It helps users keep their notes organized and easy to access.

How to use QuickNotes

  1. Type your note into the New note input box.
  2. Click the Add Note button.
  3. Review your saved notes in the Your notes section.

Features

  • Quickly add new notes.
  • Display your notes in a simple list.
  • Easy-to-use interface.

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save your note
Esc Clear the input
