Day 8: Course Reflection

1. Most Difficult Concept and How I Overcame It

The most difficult concept in this course was designing systems that can handle high traffic without losing data correctness. I initially found it challenging to understand how multiple users could access the same resource simultaneously without causing conflicts. Through the system design exercises, I learned about database transactions, constraints, stateless servers, caching, and load balancing. Practicing these concepts through the QuickNotes project and the TicketHub assignment helped me understand how they work together. Breaking a large problem into requirements, estimates, APIs, data models, architecture, and trade-offs also made system design easier to approach.

2. What I Would Improve in My Capstone

Based on the feedback received on my capstone, I would improve its reliability and testing. I would add more test cases for unexpected situations, validate how the application handles errors, and improve the documentation. I would also test the application under different usage conditions to identify performance problems before users encounter them. These improvements would make the product more dependable and easier to maintain.

3. What I Will Learn Next

Next, I will focus on backend development, database transactions, API security, and cloud deployment. I want to gain practical experience deploying applications, monitoring their performance, and securing user data. I will continue building projects and using Git and GitHub to document my progress. My goal is to develop a stronger understanding of how real-world applications are built, deployed, secured, and scaled.
